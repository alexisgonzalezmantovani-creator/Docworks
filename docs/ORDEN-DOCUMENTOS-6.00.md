# Documentos y biblioteca — orden de la interfaz

Se conserva el editor de cláusulas actual, sin asistente de pasos. Dueño y Administrador ven dos accesos: Documentos y Biblioteca de cláusulas. El asesor conserva la biblioteca y sus permisos.

Documentos abre el selector de ocho tipos. La introducción y las cláusulas aparecen en la misma pantalla, en orden de lectura. Las tarjetas indican En edición o Listo para usar según el bloqueo existente. Se retiran las pestañas internas Obligatorias / Introducción y texto base.

Las opciones de biblioteca para el documento se agrupan en un apartado desplegable inicialmente cerrado. Los estados se expresan como Siempre incluida, El asesor elige y No usar. Recomendar se configura junto a cada opción elegible; conserva los identificadores y configuraciones previas, sin una pantalla separada.

La navegación entre documentos o biblioteca confirma el descarte de borradores de cláusulas e introducción. La introducción también protege recarga y salida por el menú principal; cambiar de documento reinicia su editor para no arrastrar texto del anterior. Se mantiene el guardado actual por cláusula y la publicación explícita para asesores; no se promete un guardado único ni un borrador global.

No se modifican textos legales, modelos activos, esquema, datos ni permisos de la base. Continúa la candidata de PR #4, sin fusionar a producción.
